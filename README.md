# Ali Haider Academy Website

A complete, responsive static website for Ali Haider Academy — English learning for CSS, PMS and communication skills. Pure HTML, CSS and vanilla JavaScript; no build step.

## Run
Open `index.html` in a browser, or serve locally:
```
python3 -m http.server 8000
```

## Pages
Home, About, Courses, Foundation, CSS/PMS, Gallery, Blog, Testimonials, FAQ, Contact, Privacy, Terms.

## Customize before launch
- Replace `assets/images/mentor-profile.svg` and `gallery-*.svg` with real photos (update `src` paths if you change extensions).
- Replace placeholder email, phone, address, statistics and testimonials.
- Contact form uses `mailto:`. For real submissions, connect Formspree/Netlify Forms in `js/contact.js`.
- Review Privacy and Terms text with a legal professional.

## Structure
`css/` styles · `js/` scripts · `assets/` images, icons, fonts · `docs/screenshots/` for screenshots.
